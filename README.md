### 👋 About Me

I'm a **Data Engineer** focused on building **reliable, scalable, and production-ready data systems**.  
I work across the full data lifecycle — ingestion, transformation, modeling, orchestration, and analytics enablement.

I care less about flashy dashboards and more about **clean data models, performant pipelines, and strong data contracts**.

### 🔧 What I Actually Do
- Design and build **end-to-end data pipelines** (batch & incremental)
- Implement **CDC-based architectures** using modern warehouses
- Develop **analytics-ready models** using dbt
- Build and optimize **lakehouse-based architectures**
- Optimize **warehouse cost & performance**
- Enable analysts and stakeholders with **trusted, well-modeled data**
